Adding or replacing a photo
---------------------------
* Overwrite a file above to swap that photo - no code change needed.
* To add another to a project, drop in e.g. hexaarm-2.jpg and copy the matching
  <img class="slide" ...> line inside that card in index.html.
* A file that is missing is skipped silently; a project with no photos at all
  falls back to its gradient icon header.
* Landscape works best - the card crops to roughly 3:2. Real photos of the built
  hardware read better than schematics, so swap those in where you have them.
